# Studio Senhorele

Site institucional e catálogo do Studio Senhorele, dedicado à curadoria de
veículos clássicos e à cultura VW Air-Cooled.

## Executar localmente

Requisitos: Node.js 20 ou mais recente.

```bash
npm install
npm run dev
```

O site ficará disponível em `http://localhost:3000`.

## Verificações

```bash
npm run lint
npm run build
```

O projeto é totalmente estático: consultas são encaminhadas ao WhatsApp
oficial e não exigem variáveis de ambiente ou backend.
